## 说明

- 两个演示都是纯前端静态页面，界面和业务规则是真实实现的，数据是内置的示例数据；
- 页面里没有任何真实企业名称，客户一律写作「示例客户 A / B / C」；
- 浏览器直接打开即可，不需要安装、不需要注册、不需要后端服务；
- 技术栈：Vue 3 + Element Plus + ECharts，库文件走公共 CDN。
